# Contributing to HX Crypto Forensics CLI

We welcome contributions that improve the usage or educational value of this tool!

## How to Contribute

1.  Fork the repo.
2.  Create a branch: `git checkout -b feature/amazing-feature`.
3.  Commit changes: `git commit -m 'Add amazing feature'`.
4.  Push to branch: `git push origin feature/amazing-feature`.
5.  Open a Pull Request.

## Rules

1.  **Educational First**: Features must teach, not just "do".
2.  **No Offense**: No cracking tools. No "fastest hash generator" (unless for benchmarks).
3.  **Strict Types**: No `any`.

## Development

- `npm install`: Install deps.
- `npm run build`: Compile TS.
- `npm test`: Run tests.
